# Practitioner Feedback

Fill this out after running one real (or realistic) IEM-PM audit. Three things only — no ratings,
no opinion survey.

## 1. The generated Audit Manifest

Attach or paste the Audit Manifest this run produced (`reports/*_AuditGap_Report_*.md`, or the
canonical findings JSON). This is the actual evidence — structured data, not your opinion of it.
Everything below is your reaction to what's in it.

## 2. What did this miss?

Free text. Anything you expected the audit to catch, given what you already know about this
project or organization, that didn't show up as a finding.

## 3. What did this catch that you didn't expect?

Free text. Anything the audit surfaced that you wouldn't have thought to check yourself, or that
changed how you'd assess this project's data integrity.
