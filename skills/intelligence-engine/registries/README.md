# registries/ — derived at runtime, never authored, never committed

**This folder ships EMPTY. That is by design.**

Registries are **generated by Stage 0** from the standards the org drops into
`knowledge/`. They are standard-derived content, so they are:

- **local-only** — gitignored (except this README);
- **paraphrase + citation anchors only** — never verbatim standard text;
- **rebuilt/refreshed** whenever `knowledge/` changes.

Registry item format: see SKILL.md Appendix E (13 attributes, from Identifier
through Reference — gap/origin fields are hints; Stages 4–5 decide per finding).

One file per standard: `<slug>.json`, where `<slug>` is the source filename in
`knowledge/`, lowercased, non-alphanumeric runs collapsed to `_` (e.g.
`PS_Scheduling_3rd.pdf` → `ps_scheduling_3rd.json`). Reused across audits by
matching `source_fingerprint` against `derivation_manifest.json`; re-derived
only when that fingerprint changes. See SKILL.md Phase 0b for the procedure.
